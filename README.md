# Project Overview

Welcome to my **Manual Quality Assurance Testing Portfolio Project** based on **SauceDemo**, a widely used e-commerce web application designed for software testing practice.

This repository demonstrates the complete **Software Testing Life Cycle (STLC)**, including test planning, test scenario # design, test case development, test execution, defect reporting, requirements traceability, and test closure.
